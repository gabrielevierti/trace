# TRACE v1.0 — Project Status

TRACE v1.0 is the complete interview/demo release. The scope is intentionally bounded to explainable digital-evidence correlation rather than claiming to be a commercial forensic suite.

## Included

- Evidence acquisition for supported macOS artifacts
- SHA-256 evidence manifests and integrity verification
- Chain-of-custody acquisition log
- Filesystem, browser, quarantine, USB and optional Unified Log artifact ingestion
- Artifact normalization
- Deterministic correlation rules with explainable confidence scores
- Observed vs inferred distinction
- Interactive evidence graph
- Searchable forensic timeline
- Evidence inspector
- Automated conservative findings
- JSON, HTML and optional PDF reporting
- Controlled validation/demo data
- Automated tests and CI
- Interview and live-demo documentation

## Deliberate boundaries

TRACE does not perform device unlocking, bypass security controls, covert collection, attribution, or automated conclusions about guilt or intent. Acquisition is limited to artifacts the operator is authorized to collect and can read.

The project is an engineering/research tool for evidence triage and correlation. Results require investigator review.
